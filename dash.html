Buka Izin Baca Dashboard (RLS Supabase)

Jalankan sekali di menu SQL Editor Supabase Anda

Agar halaman Dashboard ini bisa menampilkan daftar peserta dari tabel pendaftaran dan membuka pratinjau file dari bucket dokumen_peserta, jalankan perintah SQL berikut di SQL Editor Supabase: 

-- 1. Izinkan Dashboard membaca tabel pendaftaran
create policy "Allow read pendaftaran"
on public.pendaftaran
for select
to anon
using (true);

-- 2. Izinkan Dashboard melihat file di bucket dokumen_peserta
create policy "Allow read dokumen_peserta"
on storage.objects
for select
to anon
using (bucket_id = 'dokumen_peserta');
